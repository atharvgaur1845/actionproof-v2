# Mechanism diagnostics on the trained language agents (development, descriptive)

**Source:** `results/research/llm_mechanism.json`, written by `scripts/theory/llm_mechanism.py` on Slurm compute
from the raw training-rollout logs `/scratch/pabitra/actionproof/results/ad/rollouts/ad_*.jsonl.gz` (sha256 of each
input in `_inputs`). The table is generated by `scripts/theory/mech_table.py`.

**Model:** Tiny Aya Global with LoRA; cw_train pool, 200 steps, 4 prompts × 8 rollouts per step.

**Evidence level: development / descriptive.**
- At most two seeds per development arm.
- grpo s2/s3 are AD-C1 training runs, in progress when read: training-pool rollouts only, no cw_conf output.
- Nothing here is a confirmatory test.

## 1. Pipeline trace (code → logs)

The pipeline runs: environment reset → hidden fault → rollouts → grouping → reward → advantage → token update →
checkpoint.

1. **Hidden fault.** `pools.make_pool` draws one cw1 fault plan per task. `make_env_cw` applies it to every rollout.
2. **Group.** TRL groups the 8 completions of one prompt. **800/800 groups in every logged run have exactly 8
   rollouts and one fault plan** (`share_groups_shared_state = 1.000`).
3. **Reward.** R_V − c·n_verify, or E[R_V | trajectory] − c·n_verify for awrb*.
4. **Advantage.** Recomputed here on the same rollouts for both estimators: GRPO (Bessel std + 1e-4) and centred.
   The trained arm's own estimator is in the "train scale" column.
5. **Update.** DAPO token aggregation. The per-group read-propensity update proxy is
   u_g = Σ_i A_i (n_verify_i − mean), the update on a "read more" logit in the bandit abstraction.
   The token-level gradient was not recomputed, because the model is not loaded.

## 3. Findings

1. **Shared hidden state is the trained regime.** Every group shares one fault plan. Most clean non-degenerate
   groups vary only through reads, so they are exactly the cost-only states of Cor. 3.2:
   - grpo s0–s3: 111/146, 127/162, 122/160, 127/163;
   - nostd s0/s1: 363/434, 374/442.
2. **Per-state stake invariance holds on real rollouts.** Raising the counterfactual read cost 20× (0.05 → 1.0)
   changes GRPO's clean-group update by +7% in grpo s0 (−898.0 → −961.9) and in s1 (−1010.1 → −1083.0). The centred
   update grows 13.5× and 13.1× (−86.3 → −1162.8; −100.7 → −1321.2). The residual 7% comes from the clean groups whose
   R_V also varies (35/146 in s0).
3. **Every std-normalised run moves in the direction of its early (steps 0–19) vote.**

   | Arm | Early vote | Read share, steps 0–20 → 150–200 |
   |---|---|---|
   | grpo s0 | −0.450 | 0.191 → 0.021 |
   | grpo s1 | −0.375 | 0.205 → 0.043 |
   | grpo s2 | −0.450 | 0.186 → 0.030 |
   | grpo s3 | −0.583 | 0.219 → 0.037 |
   | awrb s0 | +0.560 | 0.298 → 0.757 |
   | awrb s1 | +0.635 | 0.375 → 0.791 |
   | awrb c30 | −1.000 | 0.169 → 0.022 |

   That is 7/7 runs. The vote's interval excludes 0 in 6/7; awrb s0's spans 0.
4. **AWRB's cost dependence enters through the sign** (Prop. 4.2). Under the RB return the clean state's β is about
   p − c. awrb s0's GRPO clean-group sweep flips sign from c = 0.05 (+2572.5) to c = 1.0 (−3521.6). At the trained
   c = 0.30 the arm stops reading.
5. **Centred arms are not predicted by the warm-start ΔQ.** At c = 0.05 the early ΔQ̂ is ≤ 0 or its interval contains
   0 in all 10 centred runs (e.g. nostd s0 −0.082 [−0.162, −0.016]). Yet reading rose in 8/10 of them; it fell in
   awrbn_ema s0 and nostd_ema s1. In the last window ΔQ̂ is positive in all 10 (+0.021 to +0.113).

   **Interpretation (exploratory).** ΔQ is on-policy. It rises as the policy learns to repair after reading
   (co-adaptation of later decisions), and the centred update follows it. Calling Dr. GRPO's update "VOI" describes
   its expected direction at the current policy. It does not predict the trajectory from the warm start.
6. **The vote stays negative for the grpo and nostd arms in every window** (−0.36 to −0.62). So a std-normalised
   update applied to the same rollouts would keep pushing reads down after ΔQ turned positive. This is the contrast
   between the two estimators on identical data.
7. **Two EMA-scaled arms collapsed** (awrbn_ema s0 0.228 → 0.068; nostd_ema s1 0.270 → 0.138). An external scale
   preserves the expected sign but not stable training (D2 gates failed, `results/ad/d2_summary.json`).

## 4. What this does and does not show

- **Shows:**
  - the theorem's preconditions hold in the trained system;
  - the per-state invariance is a property of the actual update on actual rollouts;
  - the direction of every std-normalised run matches the vote computed from its first 20 steps.
- **Does not show:**
  - causality at the trained-model level: no scale intervention was run on the LLM; the causal intervention is LAB1
    H4, in the testbed;
  - that the warm-start ΔQ predicts Dr. GRPO's trajectory;
  - any confirmatory difference. That is AD-C1, with predictions frozen in `AD_C1_THEORY_PREDICTION.md`.
- **Read proxy.** n_verify counts every read-tool call, including uninformative ones after the journal entry. A
  site-specific read-after-ok-ack proxy was not built.
