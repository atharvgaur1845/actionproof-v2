## 1. Answers to the ten audit questions

**Q1. Hidden fault states in the replay.** Every world of the registered cw1 prior for the task's requested
steps:
- the clean world (mass 0.6);
- one fault on attempt 0 of one non-post write, kind ∈ {phantom, partial (ratio 1/4, 1/2, 3/4), dup_delivery,
  lost_ack, precommit_timeout}, restricted to the kinds repairable at that site.

That gives 8–14 worlds per task (`world_prior`). Multi-fault worlds and faults on retries (k > 0) are not in the
support.

**Q2. How observational equivalence is identified.** Exact equality of every observation dict. `replay` re-executes
the trajectory's recorded calls (tool, args, by) in a fresh `CWEnv` for world z, with the same id seed, and returns
None at the first observation that differs from the record.
- **Ids.** They are `hash(id_seed, call index, draw index)` (`CWEnv._next_id`). A hidden duplicate row cannot
  shift later visible ids, so aliased worlds give byte-identical observations. This is verified by
  `tests/ad/test_ad.py::test_write_acks_identical_across_silent_worlds` and by
  `tests/ad2/test_tabular.py::test_consistent_worlds_reproduce_the_observations` (the tabular analogue).

**Q3. Weights.** The cw1 prior masses. These are the actual generating distribution: the pools draw `meta.faults`
from the same `sample_world` (`actionproof/ad/pools.py`).

One subtlety: each task in the pool has **one fixed world**. The training distribution of (x, z) is therefore the
empirical pool, not x × π₀. AWRB estimates the gradient of the prior objective E_{x, z ~ π₀}. Grpo and nostd
estimate the pool objective. With 400 tasks seen about twice, the difference matters only if the policy could
memorise task → world. It cannot, since prompts are drawn independently of faults, but this is an assumption, not
a measured fact.

**Q4. Does replay preserve the entire observable history?**
- **Yes, for the environment-visible history.** Every call is recorded in `env.trace`, including errors, unknown
  tools and calls after the episode finished (`integrity/sim/env.py:call`). Every call is replayed, including any
  `start_prefix` calls.
- **The agent's text is not replayed.** It does not need to be: it is generated by the policy from the history,
  and R_V is report-blind (`truth.score`).
- **Unparseable outputs** end the episode without an env call. They are world-independent.

**Q5. Does replay use privileged simulator state?** **Yes.** R̄ needs:
- (i) the simulator itself, able to run counterfactual worlds;
- (ii) the full prior over hidden worlds, both its support and its weights;
- (iii) each counterfactual world's final hidden state, to score R_V.

None of this is available to the policy, and none is needed at deployment. AWRB is a *training-time privileged
estimator*, in the same class as asymmetric actor-critic methods (privileged critic, unprivileged actor). The fair
comparison for its added value is therefore not only nostd (which uses nothing privileged) but also other
estimators given the same privileges. In the testbed these are `fork_act` (simulator snapshot only), `fork_bel`
and `cvc` (snapshot + prior), and `igc` (prior support only).

**Q6. Are all counterfactual outcomes compatible with the observed history?** **Yes, by construction.** A world
contributes only if *every* observation of the replayed calls equals the recorded one. On that set:
- the policy's likelihood of τ is identical (π_θ conditions only on observations);
- the environment's likelihood is the indicator 1[consistent].

So the posterior is P(z | τ) ∝ π₀(z)·1[consistent], and R̄ = E[R | τ]: an exact Rao-Blackwellisation.

Unbiasedness of ∇log p_θ(τ)·R̄ follows because ∇log p_θ(τ) is a function of τ alone. The group baseline depends on
the group's shared world through the other rollouts, but E[∇log p_θ(τ_i) | z] = 0, so a world-dependent baseline
is still unbiased (as in input-dependent baselines, Mao et al. 2019).

Tests:
- `tests/ad/test_ad.py::test_unbiased_and_rao_blackwell` (LLM environment, scripted policies);
- `tests/ad2/test_tabular.py::test_rao_blackwell_unbiased_and_lower_variance` (exact tabular).

**Q7. What happens when a counterfactual world would have produced a different observation?** It is
**discarded**, which is exactly Bayesian conditioning. The assignment's concern, that replaying the original future
calls in a world that would have shown a different observation halfway through is not a valid policy trajectory,
**does not apply to the implementation**: such worlds never enter the sum.

The concern would apply to a forked-continuation Q-value: "what would this policy have earned in world z?". The
first-stage toy AD-T0 modelled exactly that by mistake, and Amendment 1 corrected it. The cost of correct
conditioning is that **after an informative read the posterior collapses to the revealed world**: R̄ = R, and
there is no variance reduction for reading trajectories.

Re-generating the continuation in the alternative world, instead of replaying it, gives a valid trajectory for
every world. That is the belief-fork estimator (`fork_bel` in the testbed, §2 below).

**Q8. Does the method require an exact simulator?** **Yes.**
- **Determinism.** It must be deterministic given (task, world, actions, id seed), so that observation equality is
  meaningful.
- **Stochastic environments.** Observation-equivalence must become a likelihood ratio P(o | z, h) in the weights.
- **Enumerable prior.** The support must be enumerable (8–14 worlds here). With many independent faults the product
  space needs sampling or sequential pruning.

**Q9. What happens when the assumed hidden-state distribution is wrong?**
- **Revealed rollouts are unaffected.** For a trajectory whose reads revealed the world, R̄ = R regardless of the
  weights.
- **Unrevealed rollouts get the wrong mean.** A trajectory that never observed the world gets the *assumed* prior
  mean. The learner then effectively uses p̃ in place of p, and learns "verify iff p̃·q·L > c": a shifted decision
  boundary.
- **Wrong support** (the true world has zero assumed mass). `marginalise` returns r_bar = None, and the reward
  raises, so training stops. The tabular implementation falls back to the realised R.
- **Measured in TB4** (`CONTROLLED_TESTBED.md`): assumed fault rates ×0.25 and ×4, a flat 0.3 rate that wrongly
  makes the safe op faultable, and an empirical-Bayes prior estimated from revealed reads.

**Q10. Where does the reported benefit come from?** Separating the four candidate sources on the LLM development
data:

| Candidate source | Evidence | Verdict |
|---|---|---|
| Better credit assignment | awrbn (RB with the correct, unscaled advantage) is *worse* than nostd: VSC −0.060, J_c −0.025, both seeds | **No** |
| Lower reward variance | First-stage F4: RB reduces within-group R_V variance only to 0.66–0.75 of raw, because once the policy reads, R̄ = R. The awrbn gradient SNR advantage requires high repair success (AD-T0b); repair after a revealed payment fault is 0.29–0.53 | **Small, and it did not translate into learning** |
| Additional simulator information | AWRB uses the prior and replay; nostd uses neither | **Yes: privileged** |
| More reading through the group-std mirror bias | awrb keeps group std. Clean groups then vote "read iff p(1 + L) > c", independent of repair (GRPO_FAILURE_DERIVATION §3c). It reads after every write, journal included (0.91), reads most (2.61), and has the highest VSC and *not* the highest J_c | **Yes: the main source** |

**Conclusion.** AWRB's VSC advantage over nostd is explained by over-verification: a different normalisation bias
that happens to read more in a regime where reading is cheap. It is not explained by better credit assignment.
"AWRB beats nostd on VSC" is true on development data. "AWRB is a better decision-making estimator" is not
supported.

## 2. Fixing trajectory consistency for counterfactual worlds

AWRB is consistent but uninformative for reading trajectories, because the posterior collapses. Two constructive
alternatives were implemented and tested in the testbed (`actionproof/ad2/tabular/train.py`):
- **`fork_act`.** At a verification decision h, fork K continuations per action in the *actual* hidden world, with
  common random numbers across the two actions. The actual world, conditional on h, is a draw from the posterior
  b(· | h). Q̂(h, a) is therefore an unbiased estimate of the belief-level Q, and the difference is an unbiased
  estimate of the decision's VOI under the current continuation policy. This needs a simulator snapshot only; no
  prior.
- **`fork_bel`.** The same, with each fork's world drawn from the posterior b(· | h). Each branch re-generates its
  continuation in its own world, so every fork is a valid policy trajectory. This needs the snapshot *and* the
  prior. It has the same expectation as fork_act and lower across-world variance.

Their results are in `CONTROLLED_TESTBED.md` and `ALGORITHM_CANDIDATES.md`.

## 3. Other implementation findings

1. **Every first-stage rollout uses env seed 0 and id seed 0.** The code is
   `seed = uuid.UUID(rid[3:].ljust(32, "0")).int % 2**31`. The zero padding fills the low 80 bits, so the modulus is
   always 0 (checked over 1,000 draws). For AWRB this is harmless, since replay uses the same seed. Any randomness
   meant to differ across rollouts through the env RNG does not.
2. **The read cost counts every read tool**, including `get_purchase_order` and `get_journal_entries`.
   Journal reads are never informative under cw1, by construction of the prior.
3. **c = 0.30 intervention (tasks 1209 and 1211).** Both awrb and awrbn stop reading entirely (0 reads, VSC 0.707).
   As first-stage F6 anticipated, this run cannot distinguish the mirror bias from the VOI rule.
4. **awrb and awrbn have no defined behaviour when the actual world is outside the prior.** Training raises
   (`base_value`). Every pool world is in the prior (`test_pool_worlds_are_in_prior`), so this never happened.
