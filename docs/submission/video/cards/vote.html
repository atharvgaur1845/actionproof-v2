THE MECHANISM · paper/main_v4.pdf §3 · stated assumptions

One task, one hidden world, one group.

1

GRPO samples a group

All rollouts of one task share its fault plan: the same database, the same silent fault.

2

Standardise inside the group

Rewards are divided by the group's own spread, so each hidden state's stakes (how much a missed fault costs) cancel out.

3

What survives is a vote

The decision to check follows Σ w(z)·sign βz: which states prefer checking, not by how much.

Why it matters. A rare, costly fault says “check”; the common clean state says “skip, reads cost”. The value of checking can be large while the vote still says skip. Exact as ε → 0 with a shared group law; the vote form needs deterministic returns within each state.
