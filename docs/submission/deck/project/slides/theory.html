THE MAIN RESEARCH RESULT · paper/main_v4.pdf

When a GRPO group shares a hidden world, the update counts votes, not stakes.

Theory (stated assumptions)

Rollouts of one task share its fault plan. Group-std normalisation then cancels each state's reward scale (exact as ε → 0). With deterministic within-state returns, a costly verify decision follows a vote of signs, not the value of checking.

Registered testbed: 731 cells

GRPO's learned decision predicted in 721 of 721; it follows the vote in all 77 cells where vote and value disagree. H6 not supported (53/75); H7 untestable.

3.35B Cohere tool agent (AD-C1)

Std-free beats GRPO by +0.120 verified completion [0.088, 0.153]. Every GRPO seed ends at the warm start's no-read behaviour: a degenerate arm, so p = 0.016 is the test's floor.

Not a new optimiser and not a universal GRPO failure: a warning about a common training setup, and evidence for when existing centred estimators keep the value of information.

Registered: PREREGISTRATION_TH1.md, PREREGISTRATION_AD_C1.md. Cost intervention AD-C2: one seed per arm, results reported separately. Simulator only.
