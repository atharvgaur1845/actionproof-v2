One deterministic episode per task; 440 locked tasks, the same tools, budget and verifier for every policy. B4 reads the record with consistent reads before any retry and is a hand-written reference, not a learned model.

The obvious engineering fixes each fail on a different reality. Idempotency keys help, but bounded retry still falsely completes on about half the tasks because it never reads the record. Only reconciliation, reading the authoritative record before deciding, gets false completion to zero. That reference is scripted. The question is whether a small model can learn it.
