REGISTERED TXN H3 · 320 IN-DISTRIBUTION TASKS

Duplicate mutations: D 0.024 against 0.191 for bounded retry with idempotency keys. Passes. Fewer unnecessary retries: fails, so the registered family is not supported.

Most of B3’s duplicates are injected by the environment, and it never reads them back. Among those it could cause: D 15 of 2430 episodes, B3 11 of 270.

REGISTERED P4 · WARM START, NO GRPO · 3 SEEDS

Randomised demonstrations: renamed tools 0.137 → 0.741; unseen four-step workflow 0.268 → 0.842; no cost on the P1 test (+0.048).

The RL agent D itself still scores 0.20 on renamed tools.

REGISTERED P5 · ONE SFT SEED PER BASE

The same recipe on four more Cohere bases: Fire 0.018 → 0.686, Water 0.011 → 0.639, Earth 0.012 → 0.704, Aya Expanse 8B 0.076 → 0.772.

Sampled VSC, paired task bootstrap. One SFT seed per P5 base: a task-level test with each model fixed, not training-seed robustness.

Recovery demonstrations are what work. The registered P1 test: the recovery-start agent completes about half; recovery SFT reaches 0.772; recovery SFT then GRPO reaches 0.819. Do not read the 0.772 to 0.819 gap as GRPO's effect: the arms are not nested. On the transaction benchmark the trained agent leaves far fewer duplicates than bounded retry, both injected ones it repairs and ones it could cause, but the registered family fails on unnecessary retries. Randomised demonstrations fix procedure replay in the warm start, not in the RL agent. Four more Cohere bases learn the same recipe.
