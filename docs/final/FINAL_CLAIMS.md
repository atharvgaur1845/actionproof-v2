# Final claims ledger (presentation, website, video)

The source of truth for every claim on a slide, on the website or in the video. Created 2026-11-22 01:27 IST.
- Every value is read from the file named here.
- The machine-checked ledger for the paper and README is `claims/claims.yaml` (`python scripts/s2_numcheck.py`).
- The website reads the same files at build time (`scripts/site_procure.py`, tested by `tests/product/test_site_procure.py`).

**Conventions:**
- "Seeds" means independent training runs.
- Intervals are 95% paired task bootstraps that hold the trained models fixed. They show task-sampling uncertainty, not how a new training run would vary.
- Seed-level evidence is stated separately.
